Java OOPS Foundation

Study notes — Core Concepts, Project Structure & Practice Programs

Foundation of OOPS

  • Object — An instance of a class
  • Method — A block of code that does a specific task
  • Class — Collection of methods, variables and objects (the blueprint)

Pillars of OOPS

1. Inheritance
2. Abstraction (Inheritance + Polymorphism)
3. Polymorphism
4. Encapsulation

Java Project Hierarchy

Project > Packages > Class > Method > Code

Project — a big folder for the whole application

  • Contains all your code, libraries, config files, and resources
  • Example: a project named SeleniumTests might contain all test cases, dependencies (like Selenium), and reports

Package — a smaller folder that organizes code

  • Groups similar classes together
  • Keeps code organized
  • Avoids name conflicts
  • Helps in reusing code

Class — a blueprint for creating objects

  • Contains variables and methods
  • Used to define behavior or logic

Method — a task or function inside a class

  • A block of code that performs a specific action
  • Can be called whenever that action is needed

Compile vs Run

TermMeaning
CompileConvert code to byte code so the system understands it (Compile Time — during coding)
RunConvert and run Java-understandable code (Run Time — while the program executes)

Eclipse Shortcuts

  • Ctrl + Shift + F — Align / format the code
  • Ctrl + Space — Auto-complete method names, variables, classes, etc.
  • Ctrl + 2, then L — Get / assign a return type for any value
  • Ctrl + Click — Navigate through the project

Facts:

  • println — prints and moves to the next line
  • print — prints and stays on the same line

Program 1 Variables & Data Types

DataTypes.java

package test.learn;

public class DataTypes {

    // String is a non-primitive datatype, mostly used
    String name = "Alex Praba"; // Collection of characters
    int age = 22;
    String gender = "Male";
    boolean educationCompleted = true;

    // rarely used
    byte experience = 4;
    short height = 176;
    long phone = 9876543212l;
    float temp = 96.4f;
    double d = 34567.6543;
    char c = 'A';

    public void heightFunction() {
        //Alex Praba's height is 176
        System.out.println(name+"'s height is "+height);
    }

    public void personalDetails() {
        // Alex Praba whose age is 22 and gender is male, has the temperature of 96.4%
        System.out.println(name + " whose age is " + age + " and gender is " + gender
            + "male, has the temperature of " + temp + "%");
    }

    public static void main(String[] args) {
        //ClassName objectName = new ClassName();
        DataTypes on = new DataTypes();
        on.heightFunction();
    }
}

Parameterized Methods

ParameterizedMethods.java

package polymorphism;

public class ParameterizedMethods {

    public void employee(String name, int age, float exp) {
        //Ramya has been hired who is 20 years old 0.5 years of experience
        System.out.println(name+" has been hired who is "+age+" years old "+exp+" years of experience");
    }

    public void activeFunction(String name, boolean active) {
        //Is Alex an active employee? false
        System.out.println("Is "+name+" an active employee? "+active);
    }

    public static void main(String[] args) {
        ParameterizedMethods obj = new ParameterizedMethods();
        obj.employee("Ramya", 20, 0.5f);
        obj.employee("Alex", 22, 1.5f);
        obj.employee("Prem", 23, 2.2f);
        obj.activeFunction("Alex", false);
    }
}

Return Type

ReturnType.java

package polymorphism;

public class ReturnType {

    private int alexAmount(int alex) {
        return alex;
    }

    private int ramyaAmount(int ramya) {
        return ramya;
    }

    private int premAmount(int prem) {
        return prem;
    }

    public static void main(String[] args) {
        ReturnType obj = new ReturnType();
        int alexAmountSent = obj.alexAmount(750);
        int ramyaAmountSent = obj.ramyaAmount(1500);
        int premAmountSent = obj.premAmount(750);

        int total = alexAmountSent + ramyaAmountSent + premAmountSent;
        System.out.println(total);
    }
}
