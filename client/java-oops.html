Java Project Hierarchy

Project > Packages > Class > Method > Code

1. Project - TataConsultancyServices - Pascal Notation

A Project is like a big folder that contains everything you need to build an application.

🛠 In coding:

  • It has all your code, libraries, config files, and resources.
  • Example: A project named SeleniumTests might contain all your test cases, dependencies (like Selenium), and reports.

2. Package - tata.consultancy.services - Camel Notation

A Package is like a small folder inside the project that helps organize your code.
Contains similar classes.

🧠 Why it's useful:

  • Keeps your code organized
  • Avoids name conflicts
  • Helps in reusing code

3. Class - TataConsultancyServices - Pascal Notation

A Class is like a blueprint to create something (usually objects).

🧱 In Java:

  • A class contains variables and methods
  • You use it to define behavior or logic

4. Method - tataConsultancyServices - Camel Notation

A Method is like a task or function inside a class. It tells Java what to do.

💬 In Java:

  • A method is a block of code that performs a specific action
  • You can call it whenever you need that action

Parameterized Methods:

package polymorphism;

public class ParameterizedMethods {
    public void employee(String name, int age, float exp) {
        //Ramya has been hired who is 20 years old 0.5 years of experience
        System.out.println(name+" has been hired who is "+age+" years old "+exp+" years of experience");
    }

    public void activeFunction(String name, boolean active) {
        //Is Alex an active employee? false
        System.out.println("Is "+name+" an active employee? "+active);
    }

    public static void main(String[] args) {
        ParameterizedMethods obj = new ParameterizedMethods();
        obj.employee("Ramya", 20, 0.5f);
        obj.employee("Alex", 22, 1.5f);
        obj.employee("Prem", 23, 2.2f);
        obj.activeFunction("Alex", false);
    }
}

Return Type:

package polymorphism;

public class ReturnType {
    // int alex = 750;
    // int ramya = 1500;
    // int prem = 750;

    private int alexAmount(int alex) {
        return alex;
    }

    private int ramyaAmount(int ramya) {
        return ramya;
    }

    private int premAmount(int prem) {
        return prem;
    }

    public static void main(String[] args) {
        ReturnType obj = new ReturnType();
        int alexAmountSent = obj.alexAmount(750);
        int ramyaAmountSent = obj.ramyaAmount(1500);
        int premAmountSent = obj.premAmount(750);

        int total = alexAmountSent + ramyaAmountSent + premAmountSent;
        System.out.println(total);
    }
}

package test.learn;

public class StaticVariables {
    private void nameMethod() {
        System.out.println("My name is Alex");
    }

    private void salaryMethod() {
        System.out.println("My salary is 2000");
    }

    private void cityMethod() {
        System.out.println("I am in Chennai");
    }

    private void climate() {
        System.out.println("Chennai is so Cool today");
    }

    private void prediction() {
        System.out.println("Rain is expected tomorrow");
    }

    private void personalDetails() {
        this.nameMethod();
        this.cityMethod();
        this.salaryMethod();
    }

    private void commonData() {
        this.climate();
        this.prediction();
    }

    public static void main(String[] args) {
        StaticVariables obj = new StaticVariables();
        obj.personalDetails();
        obj.commonData();
    }
}
