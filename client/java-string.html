STRING:

Collection of characters or words enclosed within double quotes
String is an immutable object

String implements 3 Interfaces:

  1. Serializable
  2. Comparable
  3. CharSequence (String, StringBuffer, StringBuilder)

String Functions:

  • charAt(): It is used to print the particular character
  • length(): It is used to find the length of the String
  • contains(): Contains() is a method, is used to check the particular character or word in the string
  • Equals(): equals is a method is used to check our string index is true or false
  • Equalsignorecase(): It is like a equals() method but it is not case sensitive
  • split(): split() is a method, is used to split the string by space or character or word or whatever
  • toUpperCase(): is used to convert the string into uppercase
  • toLowerCase(): is used to convert the string into lowercase
  • substring(): It is used to print from, which character we want in the string index
  • indexOf(): It is used to print the position of the character in the string (If multiple characters are present, it will take the first position)
  • lastIndexof(): If multiple same character, it takes last one
  • replace(): replace() is a method, it is used to replace the index character or word
  • isEmpty(): It is used to check the index length is zero
  • startsWith(): It is used to check the index starts with particular word or character
  • endsWith(): It is used to check the index ends with particular word or character
  • compareTo(): It is a method, it is used to compare the character based on ASCII value
  • concat(): It is used to merge 2 or more string values
  • trim(): The .trim() method removes only leading and trailing whitespace (like spaces, tabs, or newlines) from the string. It does not touch spaces inside the string.
  • join(): It is used to join multiple string with a character

Mutable:

  • we can't store duplicate values in the same memory.
  • We can change the value in memory
  • In concatenation, it takes same memory (append())

Immutable:

  • We can store more duplicate value in same memory
  • We can't change the value in memory
  • In concatenation, it creates new memory (concat())

String Buffer: (New keyword)

  • Same as String, Collection of characters or words enclosed within double quotes
  • Mutable
  • Also a child of CharSequence (Interface)
  • Synchronized
  • Thread-Safe

String Builder: (New keyword)

  • Same as String, Collection of characters or words enclosed within double quotes
  • Mutable
  • Also a child of CharSequence (Interface)
  • Non-Synchronized
  • Not Thread-Safe
