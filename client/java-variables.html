Types of Variables:

  1. Local Variable - Accessed within a method, a block or a constructor
  2. Global/Instance Variable - Global access throughout the class or even other classes when inheriting
  3. Static Variable - A static variable in Java is a class-level variable — which means it is shared by all instances (objects) of that class instead of each object having its own copy

Fact:

Static Variables or Methods can be accessed inside Non-Static methods
Non-Static Variables or Methods cannot be accessed inside Static methods

  2. Variables

package test.learn;

public class Variables {
    String employee1, employee2, employee3;
    int empID1, empID2, empID3;

    void ramya() {
        employee1 = "Ramya";
        empID1 = 1234;
        System.out.println(employee1+" has ID "+empID1);
    }

    private void prem() {
        employee2 = "Prem";
        empID2 = 1224;
        System.out.println(employee2+" has ID "+empID2);
    }

    private void alex() {
        employee3 = "Alex";
        empID3 = 1223;
        System.out.println(employee3+" has ID "+empID3);
    }

    public static void main(String[] args) {
        Variables var = new Variables();
        var.alex();
        var.ramya();
        var.prem();
    }
}

package test.learn;

public class TypesOfVariables2 {
    // These are GLOBAL or INSTANCE variables (accessible throughout the class)
    int a, b, c, d;

    // This method uses both global and local variables
    private void method1() {
        // Assigning values to global variables
        a = 2;
        b = 3;
        c = 4;

        // Local variable (only exists inside this method)
        int result = a + b + c;

        // Assigning result to global variable 'd'
        d = result;

        System.out.println("---- Inside method1 ----");
        System.out.println("Sum using global variables a, b, c: " + result); // 9
        System.out.println("Value stored in global variable 'd': " + d);
    }

    private void method2() {
        // Local variable 'a' (shadows global 'a')
        int a = 10;

        // Using local 'a' and global b & c
        b = 3;
        c = 4;
        d = a * b * c;

        System.out.println("---- Inside method2 ----");
        System.out.println("Now, 'a' = "+a+" is local, b = "+b+" is global, c = "+c+" is global");
        System.out.println("Result (local a * global b * global c): " + d); // 120

        // If you want to print global 'a' specifically:
        System.out.println("Global variable 'a' is still: " + this.a); // still 2
    }

    public static void main(String[] args) {
        TypesOfVariables2 t = new TypesOfVariables2();
        t.method1();
        t.method2();

        // Using global variable 'd' in main method
        System.out.println("---- Inside main ----");
        System.out.println("Final value of global 'd': " + t.d); // 120
    }
}

Static, Final and Non-static Global Variable:

Static:

public class GoodStudent {
    static String student = "Ganesh";

    public static void main(String[] args) {
        GoodStudent gs1 = new GoodStudent();
        gs1.student = "Alex";

        GoodStudent gs2 = new GoodStudent();
        gs2.student = "Prem";

        student = "Ramya";

        // What is the output for below statements?
        System.out.println("Clever Student is: " + gs1.student); // Ramya
        System.out.println("Clever Student is: " + gs2.student); // Ramya
        System.out.println("Clever Student is: " + student); // Ramya
    }
}
