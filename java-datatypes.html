Type Casting:

🔹 What is Typecasting?
Typecasting is the process of converting a variable from one data type to another.

There are two types:

  1. Widening (Implicit Typecasting)
  2. Narrowing (Explicit Typecasting)

✅ 1. Widening Typecasting (Automatic / Safe) (Upcasting)

  • Happens when converting smaller to larger data types.
  • No data loss.

Example:

int num = 10;
double d = num; // int to double (widening)
System.out.println(d); // Output: 10.0
From → ToTypeExample
int → doubleWideningdouble d = 10;
double → intNarrowingint i = (int) 10.99;
char → intWideningint code = 'A'; // 65
int → charNarrowingchar ch = (char) 66; // B

Flow:
byte → short → int → long → float → double

✅ 2. Narrowing Typecasting (Manual / Risky) (Downcasting)

  • Happens when converting larger to smaller data types.
  • Might lose data or precision.
  • Needs explicit cast using (type).

Example:

double d = 9.78;
int num = (int) d; // double to int (narrowing)
System.out.println(num); // Output: 9

TypeCasting:

package common;

public class Simple {
    //byte → short → int → long → float → double
    public static void main(String[] args) {
        float f = 10.5f;
        double d = f;
        System.out.println(d);// Widening Type Casting (float to double)

        byte b = 5;
        long l = b; //Widening Type Casting (byte to long)
        System.out.println(l);

        double d2 = 20.5;
        float f2 = (float) d2; //Narrowing Type Casting (double to float)
        System.out.println(f2);

        double d3 = 30.5;
        int i = (int) d3;
        System.out.println(i);

        int i2 = 40;
        float f3 = (float) i2;
        System.out.println(f3); //40.0

        byte c = 10;
        long l1 = c;
        short c2 = (short) l1;
        int i3 = c2;
        float f4 = i3;
        long l2 = (long) f4;
        System.out.println(l2);
    }
}
