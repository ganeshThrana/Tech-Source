Scanner:

Gets user input in console

Syntax: Scanner sc = new Scanner(System.in);

Syntax: to get the values from the user

  • Byte - nextByte();
  • Short - nextShort();
  • Int - nextInt();
  • Long - nextLong();
  • Float - nextFloat();
  • Double - nextDouble();
  • Char - next().charAt(0);
  • String - next();
  • String - nextLine();
  • Boolean - nextBoolean();

String:

nextLine() is used to include space
String s = sc.nextLine();

Program 1:

package org.tcs.pack;

import java.util.Scanner;

public class TCS1 {
    public static void main(String[] args) {
        //System.out.println("Alex");
        Scanner scanner = new Scanner(System.in);

        System.out.println("Please enter the Company Name: ");
        String company = scanner.nextLine();

        System.out.println("Please enter the Age: ");
        int age = scanner.nextInt();
        scanner.nextLine();

        System.out.println("Please enter the City Name: ");
        String city = scanner.nextLine();

        System.out.println("Please enter the Salary: ");
        float salary = scanner.nextFloat();

        System.out.println("Is he active?");
        boolean active = scanner.nextBoolean();

        System.out.println("Alex is working in "+company);
        System.out.println("Alex is "+age+ " years old! and is "+active);
        System.out.println("Alex is living in "+city+ " and earning "+salary+" LPA");
    }
}
